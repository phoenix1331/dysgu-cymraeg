# Common Verb Conjugations

> [!info] Essential Verb Forms
> Beyond "bod" (to be), mastering common verb conjugations is crucial for expressing actions in different tenses. This module covers regular patterns and key irregular verbs you'll use daily.

---

## Regular Verb Patterns

Welsh verbs follow predictable patterns in most tenses. The verb-noun (like the infinitive) is the base form.

### Present Tense (Continuous)

**Pattern: Bod + yn + verb-noun**

```
Dw i'n siarad
DOO een SHAHR-ad
I am speaking

Mae hi'n canu
MIGH heen KAN-ee
She is singing
```

> [!tip] Most Common Pattern
> This is the most common way to express present actions in Welsh. You've already learned this with "bod"!

### Short Future (Going to...)

**Pattern: Bod + yn mynd i + verb-noun**

```
Dw i'n mynd i siarad
DOO een mind ee SHAHR-ad
I'm going to speak

Mae e'n mynd i ganu
MIGH een mind ee KAN-ee
He's going to sing
```

### Perfect Tense (Have done...)

**Pattern: Bod + wedi + verb-noun**

```
Dw i wedi siarad
DOO ee WEH-dee SHAHR-ad
I have spoken

Mae hi wedi canu
MIGH hee WEH-dee KAN-ee
She has sung
```

## Regular Verb Conjugation Tables

### Present/Future Tense (Literary/Formal)

Most verbs follow this pattern (using **siarad** - to speak):

| Person | Welsh | Phonetic | English |
|--------|-------|----------|---------|
| I | Siaradaf i | shahr-AD-av ee | I speak/will speak |
| You (sing) | Siaradi di | shahr-AD-ee dee | You speak/will speak |
| He/She | Siarada fe/hi | shahr-AD-ah veh/hee | He/She speaks/will speak |
| We | Siaradwn ni | shahr-AD-oon nee | We speak/will speak |
| You (pl) | Siaradwch chi | shahr-AD-ookh khee | You speak/will speak |
| They | Siaradan nhw | shahr-AD-an hoo | They speak/will speak |

> [!note] Spoken vs Written Welsh
> These forms are mostly used in formal/literary Welsh. In spoken Welsh, use "Dw i'n siarad" etc.

## Imperative Forms (Commands)

### Singular Informal (ti)

Most verbs use the **verb-stem** alone:

| Verb | Command | Phonetic | English |
|------|---------|----------|---------|
| mynd | Cer! | KAIR | Go! |
| dod | Dere!/Tyrd! | DEH-reh/TEERD | Come! |
| siarad | Siarad! | SHAHR-ad | Speak! |
| gwrando | Gwranda! | GWRAN-dah | Listen! |
| edrych | Edrych! | ED-reekh | Look! |
| aros | Aros! | AR-oss | Wait! |
| bwyta | Bwyta! | BOO-ee-tah | Eat! |
| yfed | Yf! | UHV | Drink! |
| canu | Cana! | KAN-ah | Sing! |
| rhedeg | Rhed! | RHED | Run! |

### Plural/Formal (chi)

Add **-wch** to the verb stem:

| Verb | Command | Phonetic | English |
|------|---------|----------|---------|
| mynd | Ewch! | EH-ookh | Go! |
| dod | Dewch! | DEH-ookh | Come! |
| siarad | Siaradwch! | shahr-AD-ookh | Speak! |
| gwrando | Gwrandewch! | gwran-DEH-ookh | Listen! |
| edrych | Edrychwch! | ed-REEKH-ookh | Look! |
| aros | Aroswch! | ar-OSS-ookh | Wait! |
| bwyta | Bwytewch! | boo-ee-TEH-ookh | Eat! |
| yfed | Yfwch! | UHV-ookh | Drink! |
| canu | Canwch! | KAN-ookh | Sing! |
| rhedeg | Rhedwch! | RHED-ookh | Run! |

### Negative Commands

Use **Paid** (singular) or **Peidiwch** (plural) + â + verb-noun:

```
Paid â mynd!
PIDE ah MIND
Don't go! (singular)

Peidiwch â siarad!
PAYD-yookh ah SHAHR-ad
Don't speak! (plural)

Paid â phoeni
PIDE ah PHOY-nee
Don't worry
```

## Common Mistakes to Avoid

### 1. Mixing Tense Patterns

**Wrong:**
```
Dw i wedi mynd i fynd
(Mixing perfect and future)
```

**Right:**
```
Dw i wedi mynd (I have gone)
Dw i'n mynd i fynd (I'm going to go)
```

### 2. Forgetting Mutations

**Wrong:**
```
Dw i wedi gweld cath
```

**Right:**
```
Dw i wedi gweld cath (correct - no mutation after wedi)
BUT: Es i i Caerdydd (soft mutation after i)
```

### 3. Using Literal Translation

**Wrong:**
```
Dw i gael (I have - literal)
```

**Right:**
```
Mae gen i (I have - North)
Mae gyda fi (I have - South)
OR: Dw i'n cael (I'm getting)
```

### 4. Confusing Formal and Spoken Forms

**Formal (Written):**
```
Siaradaf i Gymraeg
```

**Spoken (Common):**
```
Dw i'n siarad Cymraeg
```

> [!tip] Stick to Spoken Forms
> When learning, focus on spoken forms (Dw i'n..., Dw i wedi...) as these are used in everyday conversation.

## Compound Tenses Summary

### Present Continuous
**Bod + yn + verb-noun**
```
Dw i'n gweithio (I'm working)
```

### Perfect (Have done)
**Bod + wedi + verb-noun**
```
Dw i wedi gweithio (I have worked)
```

### Near Future (Going to)
**Bod + yn mynd i + verb-noun**
```
Dw i'n mynd i weithio (I'm going to work)
```

### Past Continuous (Was doing)
**Bod (past) + yn + verb-noun**
```
Roeddwn i'n gweithio (I was working)
```

### Past Perfect (Had done)
**Bod (past) + wedi + verb-noun**
```
Roeddwn i wedi gweithio (I had worked)
```
