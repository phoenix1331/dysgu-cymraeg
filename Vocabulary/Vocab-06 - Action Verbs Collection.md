## Practice Tips

### Learning Strategy
1. **Focus by category** - Master one theme at a time
2. **Use in sentences** - Don't just memorize, practice in context
3. **Learn mutations** - Pay attention to soft mutations especially
4. **Practice daily** - Use 5-10 new verbs each day
5. **Create your own sentences** - Apply to your daily activities

### Common Mutation Patterns
- **Soft mutation (most common):**
  - c → g (canu → ganu)
  - p → b (prynu → brynu)
  - t → d (torri → dorri)
  - g → [disappears] (gwneud → wneud)
  - b → f (bod → fod)
  - d → dd (dweud → ddweud)
  - m → f (mynd → fynd)
  - ll → l (llwyddo → lwyddo)
  - rh → r (rhoi → roi)

- **After yn (progressive):** No mutation usually
  - Dw i'n cerdded (I'm walking)
  - Mae hi'n canu (She's singing)

- **After i/wedi:** Soft mutation common
  - Rhaid i fi fynd (I have to go)
  - Dw i wedi gweld (I have seen)

### Example Sentence Patterns

**Present/Progressive:**
- Dw i'n + verb-noun (I am [verb]ing)
- Dw i'n cerdded (I'm walking)
- Mae hi'n siarad (She's speaking)

**Past:**
- Wnes i + soft mutation (I [verb]ed)
- Wnes i gerdded (I walked)
- Ces i weld (I saw)

**Future:**
- Dw i'n mynd i + verb-noun (I'm going to [verb])
- Dw i'n mynd i gerdded (I'm going to walk)

**Perfect:**
- Dw i wedi + verb-noun (I have [verb]ed)
- Dw i wedi cerdded (I have walked)
