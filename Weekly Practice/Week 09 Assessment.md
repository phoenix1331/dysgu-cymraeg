## Essential Emergency Phrases

**Memorize these - they could save lives:**

| **Welsh** | **Pronunciation** | **English** |
|-----------|-------------------|-------------|
| Help! / Helpu! | HELP! / HEL-pee! | Help! |
| Mae angen ambiwlans! | my ANG-en am-bee-OO-lans! | We need an ambulance! |
| Mae damwain wedi digwydd | my DAM-wine WEH-dee dig-WITH | An accident has happened |
| Galwch yr heddlu | GAL-ookh uhr HETH-lee | Call the police |
| Mae rhywun wedi brifo | my HREE-oon WEH-dee BREE-voh | Someone is hurt |
| Ble mae'r ysbyty? | bleh my-r UHS-buh-tee? | Where is the hospital? |
| Mae'n argyfwng | mine ar-GUH-voong | It's an emergency |
| Dw i mewn perygl | doo ee mewn PER-ugl | I'm in danger |
| Dw i angen help | doo ee ANG-en help | I need help |
| Arhoswch yn dawel | ar-HOS-ookh uhn DAW-el | Stay calm |
