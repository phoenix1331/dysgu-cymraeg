# Common Verbs and Actions

> [!tip] Verb-Nouns in Welsh
> Welsh uses "verb-nouns" rather than infinitives. These are used after "yn" to form continuous tenses: "Dw i'n mynd" (I am going).

## Essential Movement Verbs

| Welsh | Phonetic | English |
|-------|----------|---------|
| mynd | MIND | to go / going |
| dod | DOD | to come / coming |
| cerdded | KER-thed | to walk / walking |
| rhedeg | RHED-eg | to run / running |
| nofio | NOV-ee-oh | to swim / swimming |
| hedfan | HED-van | to fly / flying |
| gyrru | GUH-ree | to drive / driving |
| eistedd | EYESS-teth | to sit / sitting |
| sefyll | SEV-ill | to stand / standing |

### Examples

```
Dw i'n mynd i'r gwaith
DOO een MIND eer GWIGHTH
I am going to work

Mae hi'n dod adref
MIGH heen DOD AD-rev
She is coming home

Dyn ni'n cerdded i'r dre
DIN neen KER-thed eer DREH
We are walking to town

Maen nhw'n rhedeg
MINE nhoon RHED-eg
They are running
```

| defnyddio | dev-NUHTH-ee-oh | to use / using |

### Examples

## Common Patterns

### With "i" (to) + place

```
mynd i'r gwaith = going to work
mynd i'r ysgol = going to school
mynd adref = going home
dod i'r tŷ = coming to the house
```

### With "ar" (on/at)

```
edrych ar = looking at
gwrando ar = listening to
```

### With "am" (about/for)

```
siarad am = talking about
meddwl am = thinking about
chwilio am = searching for
```
