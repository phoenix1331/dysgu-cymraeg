# Basic Welsh Phrases

> [!info] Building Blocks
> These common phrases will help you start communicating in Welsh. Practice the phonetics to improve pronunciation!

## Greetings

| Welsh | Phonetic | English | Notes |
|-------|----------|---------|-------|
| Bore da | BOH-reh DAH | Good morning | Until midday |
| Prynhawn da | PRIN-hown DAH | Good afternoon | Afternoon |
| Noswaith dda | NOS-wighth THAH | Good evening | Evening |
| Nos da | NOHS DAH | Good night | When leaving/bedtime |
| Helo | HEH-loh | Hello | Informal |
| Shwmae | SHOO-my | Hello/How are you? | South Wales informal |
| Sut mae? | SEET MIGH | How are you? | Informal |
| Sut dych chi? | SEET deekh KHEE | How are you? | Formal |

## Basic Responses

| Welsh | Phonetic | English |
|-------|----------|---------|
| Iawn, diolch | YOWN, DEE-olkh | Fine, thank you |
| Da iawn | DAH YOWN | Very good |
| Gwych | GOO-eekh | Great/Excellent |
| Ddim yn ddrwg | THEEM un THROOG | Not bad |
| Diolch | DEE-olkh | Thank you |
| Diolch yn fawr | DEE-olkh un VOWR | Thank you very much |
| Croeso | KROY-so | You're welcome |

## Polite Phrases

| Welsh | Phonetic | English |
|-------|----------|---------|
| Os gwelwch yn dda | OHS GWEH-lookh un THAH | Please (formal) |
| Plis | PLEES | Please (informal) |
| Mae'n ddrwg gen i | MINE THROOG gen EE | I'm sorry |
| Esgusodwch fi | es-gee-SOD-ookh VEE | Excuse me |

## Yes/No

| Welsh | Phonetic | English | Notes |
|-------|----------|---------|-------|
| Ie/Ydw | YEH / UH-doo | Yes | Context dependent |
| Oes | OYSS | Yes (there is) | |
| Nac ydw | NAK UH-doo | No (I'm not) | |
| Nag oes | NAG OYSS | No (there isn't) | |
| Na/Nage | NAH / NAH-geh | No | |

## Introductions

| Welsh | Phonetic | English |
|-------|----------|---------|
| Beth yw dy enw di? | BEHTH you dee EN-oo DEE | What's your name? (informal) |
| Beth yw eich enw chi? | BEHTH you EYKH EN-oo KHEE | What's your name? (formal) |
| Fy enw i yw... | VUH EN-oo EE you... | My name is... |
| ...ydw i | ...UH-doo EE | ...I am |
| Dw i'n dod o... | DOO een DOD oh... | I'm from... |
| Dw i'n dysgu Cymraeg | DOO een DUH-sgee cum-RIGH-g | I'm learning Welsh |

## Useful Questions

| Welsh | Phonetic | English |
|-------|----------|---------|
| Dych chi'n siarad Cymraeg? | DEEKH kheen SHAH-rad cum-RIGH-g | Do you speak Welsh? |
| Dych chi'n siarad Saesneg? | DEEKH kheen SHAH-rad SIGHS-neg | Do you speak English? |
| Ble mae...? | BLEH MIGH...? | Where is...? |
| Beth yw hwn? | BEHTH you HOON | What is this? (masculine) |
| Beth yw hon? | BEHTH you HON | What is this? (feminine) |
