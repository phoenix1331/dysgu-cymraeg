# Dysgu Cymraeg - Welsh Learning Repository

## 🏴󠁧󠁢󠁷󠁬󠁳󠁿 Overview

This repository is a comprehensive Welsh (Cymraeg) learning system designed for self-study and daily practice. It's optimized for someone moving to or living in Wales who wants to achieve conversational fluency.

**Current Level:** Basic phrases → **Target Level:** B1 Intermediate
**Daily Time Commitment:** 30-60 minutes
**Study Method:** Grammar, vocabulary, conversation practice, and cultural immersion

## 🚀 Quick Start

### First Time Setup
1. **Start Here:** Open `General/1- Cymraeg MOC.md` - your main navigation hub
2. **Review TODO:** Check `TODO - Remaining Tasks.md` to see the development roadmap
3. **Daily Practice:** Run `.scripts/dw-cymraeg-daily` to generate today's practice note
4. **Begin Learning:** Start with `General/2- Phonetics and Pronunciation` if you're a complete beginner

### Daily Routine (30-60 minutes)
**30-minute days:**
- 10 min: Daily practice note (automated exercises)
- 15 min: Study one module or vocabulary topic
- 5 min: Progress tracker update

**60-minute days:**
- 15 min: Daily practice note
- 20 min: Grammar study or vocabulary memorization
- 20 min: Conversation dialogue practice
- 5 min: Progress tracker and reflection

## 💡 Tips for Success

1. **Consistency over intensity** - 30 min daily beats 3 hours weekly
2. **Use it in real life** - Try Welsh at shops, with neighbors
3. **Don't fear mistakes** - Welsh people appreciate the effort
4. **Immerse yourself** - Change phone to Welsh, follow Welsh accounts
5. **Find a language partner** - Practice conversations regularly
6. **Celebrate progress** - Track achievements in Progress Tracker
7. **Be patient** - Language learning is a marathon, not a sprint
